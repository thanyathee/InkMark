# InkMark

เว็บแอปสำหรับเตรียมรูปโพสต์เพจ ใช้บน iPhone ได้ทันที (ไม่ต้องลงแอป ไม่ต้องมีเซิร์ฟเวอร์ รูปไม่ถูกอัปโหลด)

1. **ปรับขนาดให้เท่ากันทั้งชุด** — 4:5 / 1:1 / 3:2 / 16:9, กำหนดแค่กว้างเท่ากัน / สูงเท่ากัน หรือ "ต้นฉบับ" (คงขนาดเดิม) · แตะรูปเพื่อลากกรอบเลือกตำแหน่งรายรูป
2. **ปรับแสงสี** — ปุ่มอัตโนมัติ (แก้รูปมืด + ให้โทนทั้งชุดใกล้กัน แบบเบาๆ) และแถบเลื่อน ความสว่าง / คอนทราสต์ / ความสด / อุ่น-เย็น ทั้งชุดหรือรายรูป
3. **ลายน้ำ #TISCOFOUNDATION** — เลือกตำแหน่งได้ 9 จุด (ค่าเริ่มต้นขวาล่าง) ห่างขอบเท่ากัน ขนาดคิดตามรูปอัตโนมัติ สีอัตโนมัติตามพื้นหลัง
4. **บันทึกทั้งหมด** — กด "บันทึกลงคลังรูป / แชร์" แล้วเลือก "บันทึกรูปภาพ"

## ใช้บนคอม
เปิดลิงก์เดียวกันในเบราว์เซอร์ จะได้แผงเครื่องมือด้านขวา · ลากไฟล์มาวางได้ · บันทึกเป็น .zip · คีย์ลัดในหน้าแก้ไข: ← → เปลี่ยนรูป, Esc ปิด

## ใช้บน iPhone
เปิดลิงก์ใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอนเหมือนแอป และใช้ออฟไลน์ได้

## โครงสร้าง
```
index.html        หน้าจอหลัก
css/style.css     หน้าตา (มือถือก่อน, รองรับโหมดมืด)
js/app.js         ควบคุมหน้าจอ นำเข้า/แก้ไข/บันทึก
js/crop.js        โหมดขนาด + คำนวณกรอบตัด
js/tone.js        ปรับแสงสี + โหมดอัตโนมัติ
js/watermark.js   ลายน้ำ + เลือกสีอัตโนมัติ
js/zip.js         รวมไฟล์เป็น .zip (บนคอม)
js/render.js      ขั้นตอนประมวลผล: ตัด/ย่อ → แสงสี → ลายน้ำ
manifest.json     ติดตั้งเป็นแอปบนหน้าจอโฮม
sw.js             ใช้งานออฟไลน์
```

ทดสอบบนคอมพิวเตอร์: `python3 -m http.server` แล้วเปิด http://localhost:8000
